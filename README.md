# 孕心智护

## 最新版入口

- [手机与电脑网页版源码](mobile/README.md)：`mobile/dist/` 是可直接用静态服务器运行的完整页面，包含手机排版、心情与孕期记录、每周简报、情绪花园和家庭协作。记录保存在各自浏览器中，不会自动跨设备同步。
- [Android、iPhone 工程及 Mac、Windows 桌面版源码](native-app/README.md)：使用同一套手机版页面；Android 和桌面版已有打包流程，iPhone 目前提供 Xcode 工程。安装包和签名密钥不放在公开仓库。
- 下方的 `web/`、`server.py` 和启动脚本保留原本地 Python 版本，方便已有用户继续使用及迁移数据。旧版记录可先导出 JSON，再在新版“我的”中恢复。

手机与电脑网页版在仓库根目录执行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory mobile/dist`，然后访问 `http://127.0.0.1:8766/`。这一地址只供当前电脑预览；公开网站需单独发布新版静态文件。

## 原本地 Python 版本

一个在当前电脑浏览器中使用的孕产期生活支持应用。无需账号、云数据库或安装前端依赖。基础功能离线运行，主动查询天气及打开社区来源链接需要联网。最新源码包说明见“源码包先读我.txt”。

## 怎样打开

先准备 **Python 3.9 或更高版本**及桌面浏览器；新安装时选择官网当前支持的稳定版本。不需要安装第三方 Python 库。详细环境准备见 **运行环境与启动说明.txt**。

1. 完整解压后，Mac 双击 **启动孕心智护.command**；Windows 双击 **start-windows.bat**。
2. 浏览器会打开 `http://127.0.0.1:8765`。
3. 使用期间，保留出现的终端窗口。它负责把记录保存在电脑上。
4. 用完可以关闭浏览器和启动窗口。下次仍双击同一个文件，原来的数据会重新出现。

如果 macOS 提示不能直接打开，可在 Finder 中右键这个启动文件，选择“打开”。不要移动或删除整个应用文件夹中的 `data` 子文件夹。

不要直接双击 `web/index.html`，它需要由启动文件开启的本地服务提供数据保存能力。源码包不包含 Python 安装程序。Windows 启动脚本尚未在真实 Windows 环境执行验证。

## 先试哪一条流程

1. 在“心情与睡眠”记录今天的感受。
2. 在“我的需要”选择一种需要，写下原始感受并确认。
3. 选择“整理成协作请求”，填写具体安排，保存后预览分享内容。
4. 顶部切到伴侣视角，接受安排，开始接手，标记完成。也可以提出修改，由妈妈修改后重新请求伴侣确认。
5. 切回妈妈视角，记录“是否有帮助”以及“额外负担”。这与完成状态分开保存。

角色切换是本机操作视角，没有密码或身份认证。它不是真正的用户权限隔离。伴侣页面不展示妈妈的心情、原始表达、备忘和反馈，但拿到这台电脑的人可以切换视角或读取本地文件。

## 保存和备份

- 需要点击“保存”或对应确认按钮；成功提示后，记录才已落到电脑文件中。未提交的输入是草稿，刷新会丢失。
- 正式数据位于 `data/data.json`，与浏览器缓存无关；正常关闭、重启和清理浏览器缓存不影响该文件。
- `data/previous.json` 是上一次成功保存前的恢复副本，不替代定期导出的备份。
- 到“数据与设置”导出备份，可以把全部记录保存成一个 JSON 文件。恢复前会预览记录数量，再确认覆盖。
- 文件损坏时应用停止写入，不会静默重置记录。可在关闭服务后保留损坏文件，将 `previous.json` 复制为 `data.json`，再重新启动；该操作恢复到上一次保存前的状态。
- “清空”会清空当前记录，同时删除恢复副本；用户自己下载的备份不会被删除。
- 数据和备份未加密，请妥善管理这台电脑与文件。
- 多个页面同时保存时，旧页面不会覆盖更新的内容，而会提示重新操作。

## 能力边界

本版使用固定内容、手动确认和明确规则，不是自由对话 AI。支持推荐根据时间、偏好、最近确认的需要、活动反馈和同类协作反馈排序，不进行临床诊断。沟通练习使用原创虚构情境与参考表达。求助页面只保存用户自行填写的联系信息，不自动呼叫、发送通知或承诺救援。

## 技术说明

界面使用原生 HTML、CSS 和 JavaScript；本地服务使用 Python 3 标准库，仅监听 `127.0.0.1:8765`。服务只开放必要的页面和数据接口，不开放整个文件夹。正式记录采用先写临时文件、再原子替换的方式保存。

开发时手动运行：`python3 server.py`。独立测试可用 `python3 -m unittest discover -s tests`，测试只读写临时目录。

## 首页陪伴小人

点击首页“捏脸与换装”可修改名字、发型、配饰、脸颊、眼睛大小与间距、微笑、肤色、发色和衣服颜色，并实时预览。点击“保存小伙伴”后外观随应用数据保存，导出备份也会包含外观；关闭编辑窗口不保存草稿。旧备份没有外观时使用默认“小暖”。

小人支持点击摸摸、打招呼、喂饼干、休息，以及区域内水平拖动；键盘左右方向键也可以移动。互动只在网页中发生，不接入 AI、摄像头或其他在线服务。系统开启“减少动态效果”时会停止循环动画。

### 2026-10-17 需求整理与推荐算法

“陪伴支持 → 我想获得帮助”新增离线候选需要与原文线索，须本人选择确认。安排追问根据缺少字段排序，简单模式最多 1 次、普通模式最多 2 次；可跳过，不擅自填写日期或负责人，私人原话不复制到共享安排。

推荐使用同阶段反馈、30 天半衰期、少量样本收缩及单独的协调负担项；旧记录没有阶段时保留但不参与新排序。用户可关闭历史参考。方法与证据范围见 [算法创新与落地核对](docs/算法创新与落地核对_20261017.md)。

可选模型接口默认关闭。仅配置环境变量并在页面确认本次发送后才调用模型，详见 [模型接口配置](docs/模型接口配置.md)。尚未配置真实模型；当前模型测试是接口契约测试，不代表模型理解能力已验证。公开静态网站与本地后端能力不同，更新本地源码不会自动发布网站。
