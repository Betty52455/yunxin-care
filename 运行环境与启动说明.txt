孕心智护 · Mac / Windows 源码包
================================

一、压缩包里有什么

完整源代码、Mac 启动文件、Windows 启动文件、使用说明、页面设计说明和测试代码。
不包含 Python 安装程序或浏览器安装程序；这是一份源码包，不是免安装的独立应用。
不包含原作者的个人记录、导出备份、Git 历史或测试截图。

二、需要的运行环境

1. Mac 或 Windows 电脑。
2. Python 3.9 或更高版本。新安装时选择官网当前支持的稳定 Python 3 版本。
3. 更新过的桌面浏览器，例如 Chrome、Edge 或 Safari。
4. 文件夹需要允许当前用户写入。请解压到桌面或文档中，不要放到只读目录。

日常运行无需 Node.js、npm、pip 包、数据库软件、Codex、账号或 API 密钥。
Python 首次下载与安装需要获取安装包；基础记录、小人互动和已收录社区内容无需联网。
主动查询天气、打开社区来源链接时需要联网。最新版说明请先阅读“源码包先读我.txt”。

三、Mac：安装与启动

Python 官方 Mac 下载页：https://www.python.org/downloads/macos/
如果已有可用的 Python 3.9 或更高版本，可跳过安装。

1. 完整解压压缩包，保留文件夹内部结构。
2. 双击“启动孕心智护.command”。
3. 浏览器应自动打开 http://127.0.0.1:8765/ 。
4. 使用时保持终端窗口打开，保存操作才能写入电脑。

如 Finder 不允许直接打开，先右键该文件选择“打开”。
如果解压工具没有保留可执行权限，可在终端输入 chmod +x 后加一个空格，
把“启动孕心智护.command”拖进终端，按回车，再双击启动。
也可在终端进入项目文件夹后运行：python3 launcher.py

四、Windows：安装与启动

Python 官方 Windows 下载页：https://www.python.org/downloads/windows/
如果安装程序提供“Add Python to PATH”选项，请勾选，以便启动脚本找到 Python。
Python 不同安装方式可能提供 py、python 或 python3 命令，脚本会依次尝试。

1. 右键压缩包，选择“全部解压”。不要直接在压缩包内部运行文件。
2. 打开解压后的文件夹，双击 start-windows.bat。
3. 浏览器应自动打开 http://127.0.0.1:8765/ 。
4. 使用时保持命令提示符窗口打开。关闭后，下次双击同一个文件即可重新启动。

也可在命令提示符中进入项目文件夹后运行：py -3 launcher.py
如果没有 py 命令，改用：python launcher.py

五、容易弄混的地方

- 不要直接双击 web/index.html。它需要配合本地服务，直接打开文件无法正常保存数据。
- 不要把 127.0.0.1 地址当作分享链接；它始终指向使用者自己的电脑。
- 同一台电脑一次只运行一份本应用。切换到另一份副本之前，先关闭旧的启动窗口；
  否则新的启动文件会打开已经运行的那份程序，使用其原来的数据位置。
- 页面打不开时，先看启动窗口是否有报错，再确认 8765 端口没有被其他程序占用。

六、源码在哪

web/index.html       网页框架
web/styles.css       颜色、字体和布局
web/app.js           页面内容与按钮交互
web/*.svg            本地图标与插画
server.py            本地数据读写服务
launcher.py          自动打开浏览器的启动逻辑
README.md            功能、保存、备份与能力边界
页面与交互设计.md     九个页面的结构和交互说明
tests/               开发者测试代码，日常使用不需要运行

七、数据保存

第一次保存记录后，应用会在自身文件夹中创建 data/data.json。
成功提示出现后，再关闭页面或启动窗口。未点击保存的输入不属于已保存记录。
重启电脑后，从同一文件夹启动即可继续使用；清理浏览器缓存不会删除这些文件。
请定期在“数据与设置”导出备份。迁移电脑时可在新电脑上通过该页面恢复备份。
分享源码给别人时，不要附带自己的 data 文件夹或个人备份。

八、验证范围

已在当前 Mac 的 Python 3.9 环境验证本地服务、数据读写和自动测试。
网页核心流程已在 Mac 的 Chrome 浏览器中验证。
Windows 启动脚本已提供，但没有在真实 Windows 电脑上执行验证。

浏览器自动化测试属于可选开发工具，需要另外配置 Node.js、Playwright 和 Chrome。
它们不是使用本应用的依赖。开发者可以查看 tests/ 内的测试脚本。
