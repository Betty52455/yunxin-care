| 参照项目 | 本项目新增或调整 | 入口 |

| FreeCBT | “只想记一句”只需一个文本框，不强制填写标题或心情；自动生成日期标题，保存到已有备忘，之后可编辑 | 陪伴支持 → 只想记一句 |
| Postpartum Wellness App | 选择产后阶段时，将一分钟休息、心情与睡眠、需要、家庭协作、表达练习、日常支持和求助信息收进已有工具区 | 陪伴支持 → 阶段选择产后 → 产后支持工具箱 |

这是交互和方法参照，代码与页面提示由本项目重新编写。没有安装上述项目，没有复制其源码、提示词全文或书籍摘录，也没有把其治疗或产品效果声明移植到本项目。

## 为什么这样做

FreeCBT 的 README 强调快速、无需先回答心情问题的使用体验。我们发现原来“只想记一句”仍打开需要标题和内容的完整备忘表单，因此本次把入口改为一个文本框，保存仍复用可靠的备忘与备份机制。

Postpartum Wellness App 将产后工具、情绪记录和资源放在一起。我们以此组织已有功能，没有新增独立大模块；它的导师连接需要后端，本项目没有导师接通按钮或服务已上线的暗示。

非暴力沟通 Skill 是给 AI 开发工具使用的表达框架工具，并非现成的网页模块。当前没有真实模型服务，因此本次提供可填写的四项表达练习，允许留空；不会伪装成 AI 自动改写。原始表达练习只存入妈妈视角的私人练习笔记，不创建需要、不创建任务、不自动分享。想采取行动时，仍通过原有的本人确认与分享预览流程。

## 方法和能力边界

- 四步表达属于已有框架，不是我们的原创算法。
- 工具箱组织方式、快速记录属于实用性改进，不能单独证明技术先进性。
- 可以突出本项目把表达练习接入需求确认、协作执行和帮助/负担反馈的完整流程。
- 本次没有加入疾病判断、治疗建议、自动联系导师或真实跨账号服务。
- 同设备角色切换仍为界面演示，不等同于真实账号权限隔离。

## 验证

使用独立虚构数据，本地版与静态浏览器版均完成浏览器测试：一句话保存和刷新保留、工具箱链接、四项表达留空/单项保存、每项 4000 字边界、无自动任务或分享、完整备份与恢复、伴侣视角不展示私人练习、390px 视口无横向溢出。测试脚本为 `tests/support-tools-browser.cjs`，需指向独立测试服务并配置 Playwright 和 Chrome 路径。

以上为工程验证，不是治疗有效性或真实手机体验研究。
