# 可选模型接口配置

目前不需要配置。没有模型时所有原有功能和离线需求整理都可使用。

未来准备好服务后，在启动 Python 的终端设置三个环境变量：

- `YUNXIN_MODEL_URL`：完整 Chat Completions 请求地址，远端必须 HTTPS，本机允许 http://127.0.0.1。
- `YUNXIN_MODEL_NAME`：服务中实际可用的模型名。
- `YUNXIN_MODEL_KEY`：该服务的密钥；某些本机服务无需设置。

不要把密钥发送到聊天中或提交 GitHub。此程序不自动读取 `.env`，只读取启动进程的环境变量。

Mac 终端示例（先替换服务地址和模型名，密钥使用隐藏输入）：

```sh
export YUNXIN_MODEL_URL='http://127.0.0.1:11434/v1/chat/completions'
export YUNXIN_MODEL_NAME='替换为已经安装的模型名'
# 仅远程服务需要密钥时执行下面两行
read -s 'YUNXIN_MODEL_KEY?请输入模型密钥：'
export YUNXIN_MODEL_KEY
python3 server.py
```

Windows PowerShell 示例（Python 启动前配置；真实 Windows 尚未实机验证）：

```powershell
$env:YUNXIN_MODEL_URL = 'http://127.0.0.1:11434/v1/chat/completions'
$env:YUNXIN_MODEL_NAME = '替换为已经安装的模型名'
# 仅远程服务需要密钥时执行
$env:YUNXIN_MODEL_KEY = [System.Net.NetworkCredential]::new('', (Read-Host '请输入模型密钥' -AsSecureString)).Password
py server.py
```

进入“陪伴支持 → 我想获得帮助”，页面会显示目标主机。勾选本次发送同意，再点“使用已配置模型整理”。只发送当前输入句子；不自动提交其他记录。

服务须支持 `/v1/chat/completions` 风格的 `messages`、JSON 输出格式及 `choices[0].message.content`。不同服务兼容性需实测。配置错误、超时、格式不合规、原文证据不匹配都会返回可见错误，不当作成功。

当前静态网站不包含 Python 后端，不会显示模型调用按钮。不要将服务密钥放进静态网页。要在公开网址接入真实模型，需另建有鉴权和调用限额的服务端；本轮没有部署这种服务。
