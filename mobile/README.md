# 孕心智护网页版

直接打开发布网址使用；无需 Python、安装或登录。原始本地版仍位于上一级目录。

## 数据
- IndexedDB 保存在访问者自己的浏览器中，应用不上传个人记录。
- 刷新、关闭再打开后记录保留；不同网址、浏览器、设备之间不共享数据。
- 使用普通浏览窗口；清除网站数据或浏览器回收存储可能删除记录，定期在“数据与设置”导出备份。
- “申请保留”请求浏览器持久存储，浏览器可能拒绝；备份仍然必要。
- 家庭协作是同一浏览器内的视角切换，没有账号和跨设备协作。
- 备份兼容本地版，恢复时检查格式并提示覆盖。原本地版记录不会自动迁移，需要自行导出再导入。

## 2026-10-15 陪伴支持更新

第二栏保留原有工具，新增两段原创虚构分支情境：产检前的担忧、产后的家务与休息。支持双视角、尝试回应、暂停续练、保存回顾。妈妈进度通过 IndexedDB 保存和备份；伴侣练习只在当前标签页暂存，不写入妈妈私人记录。

新增阶段与精力选择、1—3 分钟日常活动、需要确认引导。备孕尚无独立故事，可使用通用支持入口。引导表单不接入 AI。原始表达不会自动分享，仍需单独整理安排并预览确认。

反馈没有预选正面评价，可跳过或选“不确定”。推荐可解释需要、偏好、历史活动与协作反馈的排序影响，并允许关闭历史参考。没有新增账号或跨设备同步，也不提供诊断、治疗或效果保证。

源码：`dist/support-core.js` 为规则与情境数据，`dist/support.js` 为交互，`dist/support.css` 为界面。原有页面与数据结构兼容。

## 开发与预览
`dist/` 是完整的无依赖静态源码，使用 Python 静态服务器即可预览：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
```

入口 `dist/index.html`，交互 `dist/app.js`，存储与校验 `dist/storage.js`。无需构建。在线访问需要网络；当前版本不承诺离线打开。

这个目录提供完整网页源码和本地预览入口；将它提交到 GitHub 不会自动更新已经发布的网站。发布网站时需要使用 `dist/` 中的文件单独更新托管源。

当前手机版还包括每日记录草稿保护、孕期档案、情绪花园、每周心情简报和手机底部导航。`dist/phone-preview.html` 可在电脑浏览器里以手机外框展示真实可交互页面。

## 首页陪伴小人

点击首页“捏脸与换装”可修改名字、发型、配饰、脸颊、眼睛大小与间距、微笑、肤色、发色和衣服颜色，并实时预览。点击“保存小伙伴”后外观随应用数据保存，导出备份也会包含外观；关闭编辑窗口不保存草稿。旧备份没有外观时使用默认“小暖”。

小人支持点击摸摸、打招呼、喂饼干、休息，以及区域内水平拖动；键盘左右方向键也可以移动。互动只在网页中发生，不接入 AI、摄像头或其他在线服务。系统开启“减少动态效果”时会停止循环动画。

## 2026-10-17 手机与电脑适配

同一个公开网址适配手机与电脑。手机使用带文字的底部导航、单列卡片和底部表单；电脑保留侧栏及宽屏布局。保留原有功能和浏览器数据，增加页面过渡及减少动态效果支持。

浏览器检查覆盖 320/390 像素手机宽度与 1280 像素电脑宽度；五个主要模块在 320 像素没有页面横向溢出。测试安排保存后刷新仍可读取。未在实体 iPhone、Android 或 Windows 设备上实测。
