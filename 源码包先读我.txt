孕心智护 · Mac / Windows 最新源码包
版本日期：2026-10-14

一、先打开哪里
1. 把 ZIP 完整解压到桌面或文档文件夹。
2. 电脑需要 Python 3.9 或更高版本，以及桌面浏览器。
   官方安装包：https://www.python.org/downloads/
   本包不含 Python 安装程序，不是免安装的 exe 或 Mac app。
3. Mac：双击“启动孕心智护.command”。
   Windows：双击 start-windows.bat。
4. 浏览器会打开 http://127.0.0.1:8765/ 。使用时保留启动窗口。
5. 若 Mac 无法双击，可在项目文件夹打开终端，运行 python3 launcher.py。
   Windows 可在项目文件夹打开命令提示符，运行 py -3 launcher.py。

二、这次包含什么
最新的简约界面、毛绒小人编辑和互动、孕期记录、体重趋势、产检安排，
以及 10 条带来源链接的社区内容。社区昵称和头像是生成的展示化名。
原有心情睡眠、我的需要、家庭协作、沟通练习、日常支持、求助、备忘和设置均保留。

三、源码在哪里
web/index.html：网页骨架。
web/styles.css、web/care.css：颜色和布局。
web/app.js、web/care.js：主要功能和社区内容。
web/pet.js、web/pet.css、web/assets/：毛绒小人及素材。
web/pregnancy.js：孕周计算、身体记录校验。
web/weather.js：天气查询。
server.py：把本地版记录保存到文件。
launcher.py：启动本地服务并打开浏览器。
online/dist/：当前发布网址使用的完整静态网页源码。
tests/、online/tests/：开发者测试，日常使用不需要运行。

四、数据与网络
本地版数据保存在自身文件夹的 data/data.json，关闭重启后可继续使用。
基础记录、小人互动、已收录的社区内容无需联网。
主动查询天气、打开内容来源需要联网。
请在“我的 → 数据与设置”定期导出备份。
不要直接双击 web/index.html；请使用启动文件，否则无法正常保存。
包内不含个人记录、备份、账号凭据、Git 历史或未启用的账号接入草稿。

五、网页版源码的使用
日常使用本地版只需根目录启动文件，不必操作 online 文件夹。
若要单独预览已发布的网页版本，在本包根目录运行：
Mac：python3 -m http.server 8766 --bind 127.0.0.1 --directory online/dist
Windows：py -3 -m http.server 8766 --bind 127.0.0.1 --directory online/dist
然后打开 http://127.0.0.1:8766/，结束时在启动窗口按 Ctrl+C。
网页版记录保存在当前浏览器，与根目录启动的本地版记录相互独立。
两版可以通过导出、恢复备份迁移数据。
